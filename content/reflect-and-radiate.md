# Interactive Cognitive Simulator

Source: https://github.com/AnorakAdrianyc/reflect-and-radiate

Standalone HTML/JS component that visualizes **Introspection** vs **Diverging Cognition**.

- Multilingual: English, Simplified Chinese, Myanmar
- Canvas particle systems for inward vs outward thought
- Perspective filters and responsive layout

## Quick Start

1. Download `cognitive_simulator.md`.
2. Copy the code block, save as `index.html`, open in a browser.

## Features

| Feature | Description |
| :--- | :--- |
| Translation Engine | Dictionary object swaps UI text without reload |
| Particle System | `CanvasParticleSystem` with distinct vector physics |
| CSS Architecture | CSS variables, Flexbox/Grid |
